# Daymark Dashboard

A lightweight personal productivity dashboard built with HTML, CSS, and vanilla JavaScript. No installation, build step, or backend is required.

## Run

Open `index.html` in a modern browser. Tasks and quick links are saved in that browser's Local Storage and remain available on future visits from the same browser profile.

## Features

- Time-aware greeting with a live clock and date
- 25-minute focus timer with start, pause, and reset controls
- To-do tasks with add, edit, complete, delete, and status filters
- Custom quick links that open in a new tab
- Responsive layout for desktop and mobile screens

All data stays on the device. Clearing the browser's site data will remove saved tasks and links.
